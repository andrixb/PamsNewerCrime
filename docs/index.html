Workout-Time — browser flasher for Teensy 4.0 / 4.1

Flashes .hex firmware over USB using WebHID (the same halfkdf protocol as Teensy Loader). Chrome / Edge / Brave on any OS. The device must be in bootloader mode: hold the program button on the Teensy for ~4 seconds.

WebHID is not available in this browser. Use Chrome or Edge over HTTPS (GitHub Pages) — WebHID does not work from file:// or Firefox/Safari.
